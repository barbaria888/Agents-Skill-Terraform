# Chapter 2 — Getting Started with Terraform

## Core Idea
Deploying infrastructure with Terraform requires combining `resource` blocks (target infrastructure), `variable` blocks (parameter inputs with type/validation), `output` blocks (exported properties), and `data` blocks (read-only queries to existing cloud resources). The basic web cluster topology moves from single EC2 instances to Auto Scaling Groups (ASGs) fronted by Application Load Balancers (ALBs).

---

## Frameworks Introduced

### 1. Terraform HCL Anatomy
- **`terraform` block**: Specifies engine version requirements (`required_version`) and provider constraints (`required_providers`).
- **`provider` block**: Configures cloud provider SDK credentials, regions, and default tags.
- **`resource` block**: Declares infrastructure components to create and manage. Syntax: `resource "<PROVIDER>_<TYPE>" "<LOCAL_NAME>"`.
- **`variable` block**: Inputs passed into Terraform code. Supports `type`, `default`, `description`, `sensitive`, and `validation`.
- **`output` block**: Exposes attributes post-deployment (e.g., DNS names, IP addresses, database endpoints).
- **`data` block**: Read-only queries against existing live cloud resources (e.g., querying latest Ubuntu AMI or default VPC ID).
- **`locals` block**: Intermediate computed expressions scoped strictly to the file/module to eliminate repetitive logic.

---

## Key Concepts

- **Provider Version Pinning**: Restricting provider versions using pessimistic operator (`~> 5.0`) to avoid breaking API upgrades.
- **User Data Replacement Trigger**: `user_data_replace_on_change = true` forces EC2 instance recreation when bootstrap script changes.
- **Dynamic Data Discovery**: Using data sources (`aws_vpc`, `aws_subnets`, `aws_ami`) instead of hardcoding VPC IDs or AMI IDs.
- **Target Group & Listener Rules**: Routing HTTP/HTTPS traffic from an ALB listener to specific ASG target groups based on paths/hosts.
- **Templating (`templatefile`)**: Decoupling complex shell scripts from HCL using `templatefile("${path.module}/user-data.sh", { port = var.server_port })`.

## Code Examples

### 1. Provider Pinning & Base Configuration (`main.tf`)
```hcl
terraform {
  required_version = ">= 1.5.0"
  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "~> 5.0"
    }
  }
}

provider "aws" {
  region = var.aws_region

  default_tags {
    tags = {
      Environment = var.environment
      ManagedBy   = "terraform"
    }
  }
}
```

### 2. Variable with Validation (`variables.tf`)
```hcl
variable "server_port" {
  description = "The port the web server will listen on for HTTP requests"
  type        = number
  default     = 8080

  validation {
    condition     = var.server_port > 1024 && var.server_port < 65535
    error_message = "Server port must be an unprivileged port between 1025 and 65534."
  }
}
```

### 3. Dynamic AMI Data Source (`data.tf`)
```hcl
data "aws_ami" "ubuntu" {
  most_recent = true
  owners      = ["099720109477"] # Canonical

  filter {
    name   = "name"
    values = ["ubuntu/images/hvm-ssd/ubuntu-jammy-22.04-amd64-server-*"]
  }

  filter {
    name   = "virtualization-type"
    values = ["hvm"]
  }
}
```

### 4. Complete ALB + ASG Web Cluster Worked Example
```hcl
# Query VPC & Subnets
data "aws_vpc" "default" {
  default = true
}

data "aws_subnets" "default" {
  filter {
    name   = "vpc-id"
    values = [data.aws_vpc.default.id]
  }
}

# Security Group for ALB
resource "aws_security_group" "alb" {
  name_prefix = "web-alb-sg-"
  vpc_id      = data.aws_vpc.default.id

  ingress {
    from_port   = 80
    to_port     = 80
    protocol    = "tcp"
    cidr_blocks = ["0.0.0.0/0"]
  }

  egress {
    from_port   = 0
    to_port     = 0
    protocol    = "-1"
    cidr_blocks = ["0.0.0.0/0"]
  }
}

# Security Group for Instances
resource "aws_security_group" "instance" {
  name_prefix = "web-instance-sg-"
  vpc_id      = data.aws_vpc.default.id

  ingress {
    from_port       = var.server_port
    to_port         = var.server_port
    protocol        = "tcp"
    security_groups = [aws_security_group.alb.id]
  }
}

# Launch Template for ASG
resource "aws_launch_template" "example" {
  name_prefix   = "web-lt-"
  image_id      = data.aws_ami.ubuntu.id
  instance_type = "t3.micro"

  vpc_security_group_ids = [aws_security_group.instance.id]

  user_data = base64encode(templatefile("${path.module}/user_data.sh.tpl", {
    server_port = var.server_port
  }))

  lifecycle {
    create_before_destroy = true
  }
}

# Auto Scaling Group
resource "aws_autoscaling_group" "example" {
  name_prefix         = "web-asg-"
  vpc_zone_identifier = data.aws_subnets.default.ids
  target_group_arns   = [aws_lb_target_group.asg.arn]
  health_check_type   = "ELB"

  min_size = 2
  max_size = 5

  launch_template {
    id      = aws_launch_template.example.id
    version = "$Latest"
  }

  instance_refresh {
    strategy = "Rolling"
    preferences {
      min_healthy_percentage = 50
    }
  }

  lifecycle {
    create_before_destroy = true
  }
}

# Application Load Balancer
resource "aws_lb" "example" {
  name               = "web-alb"
  load_balancer_type = "application"
  subnets            = data.aws_subnets.default.ids
  security_groups    = [aws_security_group.alb.id]
}

# ALB Listener
resource "aws_lb_listener" "http" {
  load_balancer_arn = aws_lb.example.arn
  port              = 80
  protocol          = "HTTP"

  default_action {
    type = "fixed-response"

    fixed_response {
      content_type = "text/plain"
      message_body = "404: page not found"
      status_code  = 404
    }
  }
}

# ALB Target Group
resource "aws_lb_target_group" "asg" {
  name     = "web-asg-tg"
  port     = var.server_port
  protocol = "HTTP"
  vpc_id   = data.aws_vpc.default.id

  health_check {
    path                = "/"
    protocol            = "HTTP"
    matcher             = "200"
    interval            = 15
    timeout             = 3
    healthy_threshold   = 2
    unhealthy_threshold = 2
  }
}

# Listener Rule Routing
resource "aws_lb_listener_rule" "asg" {
  listener_arn = aws_lb_listener.http.arn
  priority     = 100

  condition {
    path_pattern {
      values = ["*"]
    }
  }

  action {
    type             = "forward"
    target_group_arn = aws_lb_target_group.asg.arn
  }
}

output "alb_dns_name" {
  value       = aws_lb.example.dns_name
  description = "The public DNS name of the ALB"
}
```

## Anti-patterns

- **Hardcoding AMI IDs or Subnet IDs**:
  - *Why it fails*: AMI IDs change per region and per update; hardcoded IDs break when changing regions or deploying new stacks. Use `data "aws_ami"` and `data "aws_subnets"`.
- **Exposing EC2 Instances Directly to the Public Internet**:
  - *Why it fails*: Directly attached Elastic IPs bypass central load balancing, TLS offloading, and web application security layers.
- **Using Inline Heredoc `user_data` Strings**:
  - *Why it fails*: Messes up HCL formatting and makes shell scripts untestable. Use external `.sh.tpl` files loaded with `templatefile()`.

---

## Key Takeaways

1. **Always Pin Provider Versions**: Use `required_providers` with `~>` version constraints.
2. **Decouple Logic with Data Sources**: Use data blocks to dynamically query cloud infrastructure metadata.
3. **Use Launch Templates Over Launch Configurations**: Launch Configurations are deprecated by AWS; Launch Templates support versioning and modern EC2 features.
4. **Enforce Zero-Downtime Rollover**: Use `create_before_destroy = true` on Launch Templates and ASGs.
